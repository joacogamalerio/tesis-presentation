\section{Motivación y marco conceptual}

\begin{frame}{Motivación}
\begin{itemize}
  \item El \textbf{conjunto de entrenamiento} contiene los ejemplos que la red ve durante el ajuste de sus parámetros.
  \item Se usa para que el modelo aprenda regularidades: qué patrones de entrada se asocian con cada salida esperada.
  \item Pero bajar el error sobre esos ejemplos conocidos no alcanza: el objetivo es responder bien ante datos nuevos.
  \item Hay \textbf{sobreajuste} cuando la red memoriza detalles del conjunto de entrenamiento en lugar de aprender reglas transferibles.
  \item El problema aparece al evaluar con datos que no pertenecen al entrenamiento: el desempeño empeora porque esos detalles memorizados no generalizan.
  \item Este es el problema que aborda la tesis: cómo reducir el sobreajuste mediante regularización estocástica.
\end{itemize}
\end{frame}

% ------------------------------------------------------------
\begin{frame}{Objetivos de la tesis}
\begin{columns}[T,totalwidth=\textwidth]
\column{0.48\textwidth}
\textbf{Objetivo principal}
\begin{itemize}
  \item Proponer y estudiar \bd{}, un mecanismo de regularización estocástica basado en una modulación multiplicativa no binaria de activaciones.
  \item Se compara contra una red base sin regularización estocástica.
  \item Se contrasta con dos regularizadores clásicos: Dropout y DropConnect.
  \item Se evalúa con un protocolo controlado sobre MNIST, usando búsqueda de hiperparámetros y evaluación final multisemilla.
\end{itemize}
\column{0.48\textwidth}
\textbf{Objetivo secundario}
\begin{itemize}
  \item Comparar cualitativamente las representaciones aprendidas por cada método.
  \item Usar autoencoders como herramienta exploratoria para visualizar diferencias internas.
  \item Analizar filtros, esparsidad representacional y esparsidad paramétrica.
  \item Interpretar si \bd{} produce una firma distinta a la de la supresión binaria clásica.
\end{itemize}
\end{columns}
\end{frame}

\begin{frame}{Regularización: idea general}
\begin{block}{Definición operativa}
Regularizar es modificar el aprendizaje para reducir el error de generalización, aunque eso no implique reducir el error de entrenamiento.
\end{block}
\vspace{0.3cm}
\begin{columns}[T,totalwidth=\textwidth]
\column{0.48\textwidth}
\textbf{Sin regularización}
\begin{itemize}
  \item Mayor libertad efectiva.
  \item Más riesgo de dependencia de patrones frágiles.
  \item Sobreajuste más probable.
\end{itemize}
\column{0.48\textwidth}
\textbf{Con regularización estocástica}
\begin{itemize}
  \item Se perturba la propagación durante entrenamiento.
  \item La red debe distribuir información de modo más robusto.
  \item Se busca mejor desempeño en datos nuevos.
\end{itemize}
\end{columns}
\end{frame}

\section{Métodos de regularización}

\begin{frame}{Dropout: apagar activaciones}
\begin{columns}[T,totalwidth=\textwidth]
\column{0.47\textwidth}
\small
\begin{itemize}
  \item En cada iteración del entrenamiento, una fracción de activaciones se anula aleatoriamente.
  \item La perturbación es binaria: cada activación queda activa o apagada.
  \item La red no puede depender rígidamente de unidades específicas.
  \item Se interpreta como entrenamiento de muchas subredes implícitas con pesos compartidos.
\end{itemize}
\column{0.50\textwidth}
\vfill
\begin{center}
\thesisimage[width=\linewidth,height=0.62\textheight,keepaspectratio]{dropconnect y dropout/10_inverted_dropout_training.jpg}{4.6cm}
\end{center}
\smallsource{dropconnect y dropout/10_inverted_dropout_training.jpg}
\end{columns}
\end{frame}

% ------------------------------------------------------------
\begin{frame}{DropConnect: apagar conexiones}
\begin{columns}[T,totalwidth=\textwidth]
\column{0.47\textwidth}
\small
\begin{itemize}
  \item La máscara aleatoria actúa sobre pesos individuales, no sobre neuronas completas.
  \item La activación puede existir, pero algunas conexiones salientes o entrantes se anulan.
  \item La conectividad efectiva cambia en cada iteración.
  \item También es una perturbación binaria.
\end{itemize}
\column{0.50\textwidth}
\vfill
\begin{center}
\thesisimage[width=\linewidth,height=0.62\textheight,keepaspectratio]{dropconnect y dropout/12_dropconnect_training.jpg}{4.6cm}
\end{center}
\smallsource{dropconnect y dropout/12_dropconnect_training.jpg}
\end{columns}
\end{frame}

% ------------------------------------------------------------
\begin{frame}{\bd: idea central}
\begin{columns}[T,totalwidth=\textwidth]
\column{0.47\textwidth}
\small
\begin{itemize}
  \item No apaga necesariamente la señal.
  \item Modula multiplicativamente la activación.
  \item Reemplaza ``apagar/conservar'' por ``modificar amplitud''.
  \item Introduce dos hiperparámetros principales: frecuencia $p$ e intensidad $\lambda$.
\end{itemize}
\vspace{0.15cm}
\begin{block}{Máscara propuesta}
\scriptsize
\[
 m_j = \begin{cases}
 1+\lambda, & \text{con probabilidad } p,\\
 1, & \text{con probabilidad } 1-p,
 \end{cases}
 \qquad \widetilde h_j = m_j h_j
\]
\end{block}
\column{0.50\textwidth}
\vfill
\begin{center}
\thesisimage[width=\linewidth,height=0.62\textheight,keepaspectratio]{14_boostdropout_training.jpg}{4.6cm}
\end{center}
\smallsource{14_boostdropout_training.jpg}
\end{columns}
\end{frame}

% ------------------------------------------------------------
\begin{frame}{Máscara normalizada y vínculo con Dropout}
\begin{itemize}
  \item El valor esperado de la máscara es
  \[
    \mathbb{E}[m_j] = 1 + p\lambda.
  \]
  \item Si se quiere preservar la escala esperada, puede usarse
  \[
    \widehat m_j = \frac{m_j}{1+p\lambda}, \qquad \mathbb{E}[\widehat m_j]=1.
  \]
  \item Si $\lambda=-1$, la máscara pasa a ser binaria sobre $\{0,1\}$.
  \item Con normalización adecuada, ese caso recupera la lógica de \textit{inverted dropout}.
\end{itemize}
\begin{alertblock}{Diferencia clave}
En esta tesis, la configuración seleccionada de \bd{} usa $p=0.7$, $\lambda=0.9$ y máscara no normalizada.
\end{alertblock}
\end{frame}

% ------------------------------------------------------------
\begin{frame}{Tres métodos en una misma familia}
\begin{table}
\centering
\small
\begin{tabularx}{0.96\textwidth}{lXXX}
\toprule
Método & Nivel de acción & Tipo de perturbación & Lectura conceptual \\
\midrule
Dropout & Activaciones & Binaria & Supresión aleatoria de unidades. \\
DropConnect & Conexiones & Binaria & Supresión aleatoria de pesos. \\
\bd & Activaciones & No binaria / multiplicativa & Modulación estocástica de amplitud. \\
\bottomrule
\end{tabularx}
\end{table}
\vspace{0.5cm}
\keymsg{Los tres métodos pertenecen a una misma familia de dilución estocástica: perturban la red durante entrenamiento, pero en distintos niveles y con distintas máscaras.}
\end{frame}

\section{Análisis cualitativo con autoencoders}

\begin{frame}{Puente hacia el análisis cualitativo}
\begin{itemize}
  \item El protocolo principal mide desempeño predictivo: error y pérdida sobre datos de test.
  \item Para complementar esa evaluación, se inspeccionan las representaciones aprendidas por cada regularizador.
  \item Los autoencoders no reemplazan la evaluación de clasificación; sirven como herramienta exploratoria.
  \item La pregunta ahora es cualitativa: qué tipo de estructura interna induce cada mecanismo de regularización.
\end{itemize}
\end{frame}

\section{Alcances, conclusiones y cierre}

\begin{frame}{Alcance de los resultados}
\begin{columns}[T,totalwidth=\textwidth]
\column{0.48\textwidth}
\begin{block}{Qué podemos afirmar}
\begin{itemize}
  \item En el protocolo estudiado, \bdn{} mejora a la red base.
  \item Supera a Dropout y DropConnect en las métricas principales.
  \item Muestra una dinámica de validación más estable.
\end{itemize}
\end{block}
\column{0.48\textwidth}
\begin{alertblock}{Qué no podemos afirmar}
\begin{itemize}
  \item Superioridad universal.
  \item Validez automática para todas las arquitecturas.
  \item Generalización directa a todos los datasets o regímenes de entrenamiento.
\end{itemize}
\end{alertblock}
\end{columns}
\end{frame}

% ------------------------------------------------------------
\begin{frame}{Limitaciones metodológicas}
\begin{itemize}
  \item Se trabajó con un subconjunto de MNIST.
  \item La arquitectura fue una red densa \textit{feed-forward} específica.
  \item La búsqueda de hiperparámetros fue acotada.
  \item La evaluación fue multisemilla, pero no exhaustiva.
  \item El análisis con autoencoders fue cualitativo y complementario.
\end{itemize}
\vspace{0.4cm}
\keymsg{Estas limitaciones no debilitan el resultado; delimitan con precisión su alcance.}
\end{frame}

% ------------------------------------------------------------
\begin{frame}{Conclusiones principales}
\begin{enumerate}
  \item \textbf{Regularización efectiva:} \bdn{} mejora a \ofn{} y mitiga el sobreajuste en el escenario estudiado.
  \item \textbf{Comparación favorable:} bajo el protocolo experimental, supera consistentemente a Dropout y DropConnect.
  \item \textbf{Mecanismo distinto:} su comportamiento sugiere una forma de regularización diferente, no una simple intensificación de Dropout.
\end{enumerate}
\vspace{0.5cm}
\begin{alertblock}{Mensaje de defensa}
La contribución central es abrir una dirección: estudiar regularización estocástica más allá de la supresión binaria.
\end{alertblock}
\end{frame}

% ------------------------------------------------------------
\begin{frame}{Trabajo futuro}
\begin{itemize}
  \item Evaluar \bd{} en otras arquitecturas: CNNs, redes más profundas, modelos residuales.
  \item Probar otros datasets y problemas de mayor complejidad.
  \item Explorar de manera más amplia el espacio de $p$, $\lambda$ y normalización.
  \item Analizar calibración probabilística y temperature scaling como diagnóstico posterior.
  \item Estudiar vínculos con física estadística, sistemas complejos y dinámica de perturbaciones multiplicativas.
\end{itemize}
\end{frame}

\section{Apéndice}

\begin{frame}{Apéndice: ecuaciones clave de \bd}
\begin{align*}
 m_j &= \begin{cases}
 1+\lambda, & \text{con probabilidad } p,\\
 1, & \text{con probabilidad } 1-p,
 \end{cases} \\
 \widetilde h_j &= m_j h_j, \\
 \mathbb{E}[m_j] &= 1+p\lambda, \\
 \widehat m_j &= \frac{m_j}{1+p\lambda} \quad \Rightarrow \quad \mathbb{E}[\widehat m_j]=1.
\end{align*}
\begin{block}{Caso límite}
Para $\lambda=-1$, la máscara se vuelve binaria; con normalización adecuada se recupera la lógica de \textit{inverted dropout}.
\end{block}
\end{frame}
